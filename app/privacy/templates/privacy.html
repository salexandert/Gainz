What Gainz Does Not Upload

  • No hosted Gainz account is required.
  • No exchange API connection is required.
  • No wallet address sync is required.
  • No transaction history is uploaded to Gainz.
  • No tax evidence files are sent to a cloud parser by Gainz.
  • Tax evidence scans default to reference-only records.
  • Audit packets copy tax evidence only when you explicitly select packet copy.

What To Review Before Sharing

  • Audit packets may include copied transaction source files.
  • Copied evidence files appear in the packet manifest with hashes.
  • Reference-only evidence lists a local path or label but does not copy the file.
  • Draft packets preserve unresolved blockers and warnings for review.
  • Review generated files with a qualified tax professional before relying on them.

Network Access

  • The normal reconciliation workflow runs locally at 127.0.0.1.
  • Website, GitHub, support, donation, and update links may use the network when clicked.
  • If your browser loads external links, that happens outside the local Gainz data workflow.

Synced Folders

  • Gainz keeps files local to the path shown above.
  • If that path is inside OneDrive, iCloud, Dropbox, or another sync folder, that provider may sync the files.
  • Use a non-synced folder for outputs you do not want backed up or shared by another service.

Delete Local Data

  • Close Gainz first so files are not in use.
  • Back up anything you need to keep.
  • Delete the local data folder, saved exports, and any audit packet folders you created.
  • Clearing the local data folder removes app saves and account metadata for that Gainz install.
