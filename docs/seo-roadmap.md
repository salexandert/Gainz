# Gainz SEO Launch Roadmap

Gainz should start SEO now, but with foundation-first work. The goal is not to chase broad "crypto tax" searches immediately. The goal is to become genuinely helpful for people searching concrete problems such as missing Coinbase basis, Cash App Bitcoin CSVs, Coinbase Convert rows, Form 8949 evidence, and local crypto tax documentation.

## Positioning

Primary phrase:

> Gainz is a local-first crypto tax audit packet and reconciliation tool.

Supporting phrases:

- Local crypto tax software.
- Crypto Form 8949 audit packet.
- Crypto cost-basis reconciliation.
- Coinbase Convert tax CSV.
- Cash App Bitcoin tax CSV.
- Current crypto holdings reconciliation.

## Product Work That Improves SEO Conversion

Search traffic only matters if the first-run experience proves value quickly. The highest conversion features are:

- Load Demo Data button.
- Run FIFO Auto Link For All Assets.
- Readiness blocker links that jump to the exact fix.
- Download/Open output folder action after export.
- Screenshots and demo packet generated entirely from synthetic data.

## Publishing Checklist

1. Enable GitHub Pages from the `docs/` folder or deploy `docs/` to <https://cryptogainz.store>.
2. Confirm every guide has a unique title and meta description.
3. Confirm `https://cryptogainz.store/sitemap.xml` loads.
4. Add Google Search Console once the domain is live.
5. Submit the sitemap in Search Console.
6. Add release download links after a public Windows build is ready.
7. Add screenshots from the synthetic demo workflow.
8. Keep donation language optional and separate from tax advice.

## Editorial Rules

- Write for people trying to solve a real reconciliation problem.
- Keep disclaimers clear: Gainz is documentation support, not tax advice.
- Show the local-first privacy benefit without attacking other products.
- Prefer screenshots, sample files, and audit packet examples over vague marketing claims.
